# AI Frontier Challenge Lab

Dashboard is the shared course hub for tasks, announcements, and course-wide discussions. Project work lives in each project's own repository under the [course organization](https://github.com/RDFZ-AI-Challenge-2026).

Use Dashboard Issues for course-wide questions; use each project's Issues for project-specific discussions. Mention **@qftgtr** when you need the teacher's response.

Use English here to practice. Write your own project descriptions and notes in English whenever possible.
